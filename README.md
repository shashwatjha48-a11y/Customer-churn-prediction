# 🎬 Netflix Customer Churn Prediction

A machine learning project that predicts whether a customer is likely to churn based on demographic, subscription, and viewing behavior.

The project includes a **Netflix-inspired black and red Streamlit interface** that allows users to enter customer information and receive a churn prediction with probability.

---

## 🚀 Features

- Customer churn prediction using Machine Learning
- Data preprocessing and exploratory data analysis
- Categorical feature encoding
- Random Forest classification
- Churn probability estimation
- Netflix-inspired Streamlit UI
- Interactive customer input
- Model saved using Joblib
